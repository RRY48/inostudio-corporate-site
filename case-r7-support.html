Р7 — Центр поддержки: обращения клиентов без задержек

Р7 — российский вендор ПО. Мы развиваем сервис центра поддержки: клиент подаёт обращение, видит статус и историю коммуникации, а команда вендора — приоритеты и сроки.

2 года
сотрудничества и развития сервиса
24/7
приём обращений без выходных
SLA
прозрачные сроки реакции и решения

🎯 Задача

  • Обращения приходили по разным каналам — часть терялась, приоритеты определялись вручную.
  • Клиент не видел статус обращения и не понимал, когда ждать решение.
  • Команде поддержки не хватало единого рабочего места с историей и приоритетами.
  • Вендору требовался прозрачный процесс с измеримыми сроками.

🛠️ Решение

  • Сделали единую точку приёма обращений с понятной формой и вложениями.
  • Добавили статусы, приоритеты и историю коммуникации по каждому обращению.
  • Реализовали роли для клиентов и команды поддержки, уведомления и напоминания.
  • Настроили интеграции с внутренними системами вендора и правила SLA.
  • Обеспечили отчётность по срокам реакции и нагрузке на поддержку.

📈 Результат

  • Обращения больше не теряются: у каждого есть статус, исполнитель и срок.
  • Клиенты видят прогресс — меньше повторных обращений и звонков.
  • Команда поддержки работает по приоритетам, а не в порядке поступления.
  • Вендор измеряет SLA и улучшает процессы на основе данных.
Технологии: PHP / Laravel · React · PostgreSQL · Redis · REST API
