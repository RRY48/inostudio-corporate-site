## Что изменено в версии 2.2 (портфолио вместо отраслей и решений)

Задача: уйти от позиционирования по отраслям и «решениям» и показать экспертизу через актуальное портфолио. Ориентир — практики лидеров рейтинга Tagline (`red_mad_robot`, `AGIMA`, `QSOFT`, `SimbirSoft`): кейсы сразу после первого экрана, метрики в заголовках, фильтры по типу работ и технологиям, «в чём мы особенно хороши» вместо отраслей.

| Вводная | Реализация |
|---|---|
| Убрать позиционирование по отраслям и решениям | Из главного меню убран пункт «Решения»: **Портфолио · Услуги · Компетенции**. В футере колонка «Решения» заменена на «Портфолио» |
| Показать экспертизу через актуальное портфолио | Главная: блок «В чём мы особенно хороши» (компетенции с доказательствами) → **актуальное портфолио** из 6 проектов с бизнес-метриками + «ещё в портфолио» + кнопка |
| Кейсы как витрина | В карточках портфолио — крупная бизнес-метрика (40+ млн документов, −30% обращений, 1000+ сотрудников и т.д.) |
| Фильтры по практикам, а не по отраслям | `projects.html` → «Портфолио»: **две группы фильтров** — тип работ (порталы, интеграции, высокие нагрузки, HR-tech, BI, ИИ) и технологии (PHP/Laravel, Node.js, React, Elasticsearch, PostgreSQL, 1С-Битрикс) |
| Доказательства экспертизы | `solutions.html` → «Компетенции»: компетенции + блок «Чем подтверждаем» с 6 кейсами и метриками + стандарты и стек |
| Цифры как доказательство | Блок «Портфолио в цифрах»: 350+ проектов, 100+ специалистов, 30+ клиентов, 20+ лет, 99,6% |

> Страницы направлений `solutions-b2b/hr/ai/bi.html` удалены вместе с позиционированием по «решениям» — их заменили «Компетенции» (`solutions.html`) и «Портфолио» (`projects.html`).

## Заметки для продакшена

- Форма демонстрационная (без сервера). Подключить обработчик заявок.
- Метрики кейсов (сроки сотрудничества, роли, стек) сверены с `inostudio.com/projects`; уточнить у команды стоит только отдельные цифры — например, «1000+ сотрудников» в LAMODA TMS.
- Авторы статей (Вдовин, Тимур, Олег, Вероника) — реальные роли/имена уточнить перед публикацией.
- Фоновое видео в hero — локальный файл `video/hero-bg.mp4` (шоурил компании, autoplay, loop).
- Идентификатор Яндекс.Карты демонстрационный.
- Шрифт Montserrat подключён через Google Fonts — для РФ заменить на отечественный хостинг шрифтов.
