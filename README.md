## Что изменено в версии 2.1

| Вводная | Реализация |
|---|---|
| Слоган — ёмкий, «кто мы», + сегментация «крупный бизнес» | Hero: **«Стратегический партнёр по цифровизации крупного бизнеса»**, `<title>`/`description` обновлены |
| Кейсы на главной — витрина экспертизы: 6 важных + «Смотреть все» | Блок «Экспертиза, которую можно открыть и прочитать»: 6 флагманских кейсов + кнопка `Смотреть все кейсы` |
| Названия кейсов — в стиле QSOFT, с главным достижением/бизнес-метрикой | Названия всех кейсов переписаны («продукт: главный результат»); 6 кейсов открываются на отдельные страницы с метриками |
| Статьи в блоге — полезные, об опыте, авторы (Вдовин, Тимур, Олег, Вероника) | 6 полноценных статей в стиле Academy MediaSoft (лид → разделы → плюсы/минусы → лайфхаки → вывод), каждая с автором |
| Темы статей | Elasticsearch в Razor, безопасность веб-систем (чек-лист), дашборды/аналитика Razor, ИИ-база знаний, интеграция ERP и портала, карьерные сайты |
| Фильтры в услугах — не сводить к 4 направлениям | `services.html`: 9 релевантных фильтров (разработка, UX, QA, интеграции, BI, ИИ, HR-tech, Битрикс, поддержка) и 12 карточек услуг |
| Блог — фильтры по рубрикам | Добавлены рубрики «Разработка и инженерия» и «Безопасность» |

> ⚠️ Метрики в названиях и на страницах кейсов — прототипные цифры для ревью-версии. Перед публикацией их нужно согласовать с проектной командой.

## Источники

- `Аудит корп сайта final.docx` — целевая структура и рекомендации

## Запуск

Откройте `index.html` в браузере — сайт не требует сборки. После открытия введите логин и пароль:

```bash
start index.html
# логин: RRY
# пароль: 4V!GhKAYugEiYzs
```
