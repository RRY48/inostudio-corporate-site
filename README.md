# Иностудио — прототип обновлённого корпоративного сайта

Прототип корпоративного сайта **inostudio.com**, разработанный на основе документа «Аудит корп сайта final» (версия 2.0 от 10 августа 2026).

**Живая версия (GitHub Pages):** https://rry48.github.io/inostudio-corporate-site/

---

## Позиционирование (4 направления)

1. **B2B-порталы и личные кабинеты** — личные кабинеты клиентов и партнёров, интеграции с ERP/CRM, B2B-порталы поставщиков и дилеров
2. **HR-tech решения** — карьерные сайты, системы управления талантами (TMS), атлас профессий
3. **ИИ-решения и интеллектуальные ассистенты** — базы знаний с ИИ-агентами, модули персонализации, предиктивные модели
4. **Аналитика данных и BI** — BI-дашборды, предиктивная аналитика, визуализация данных

## Запуск

Откройте `index.html` в браузере — сайт не требует сборки.

```bash
start index.html
```

- Форма демонстрационная (без сервера). Подключить обработчик заявок.
