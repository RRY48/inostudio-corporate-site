Razor: высоконагруженная ERP — отчётность и поиск в реальном времени

Razor — ERP-система, на которой работает бизнес крупного заказчика: закупки, продажи, склад, финансы и кадры. Иностудио — партнёр по развитию продукта: архитектура под нагрузку, поиск по большим данным, интеграции и круглосуточная поддержка.

🎯 Задача

  • Бизнес-процессы компании разнесены по разрозненным системам: данные дублируются, отчёты собираются вручную.
  • Поиск по справочникам и документам работал через LIKE-запросы: при росте данных ответ занимал секунды, а сложные выборки — минуты.
  • Требовалась архитектура, способная выдержать пиковые нагрузки (закрытие периода, массовые операции) без деградации.
  • Нужна отчётность «здесь и сейчас»: руководители ждали цифры днями.

🛠️ Решение

  • Спроектировали модульную архитектуру: монолитное ядро разбили на сервисы с чёткими границами и API.
  • Развернули Elasticsearch-кластер для полнотекстового поиска по справочникам, документам и журналам операций — с переключением индексов через aliases без простоев.
  • Построили витрины данных и ETL-пайплайны: отчётность переехала с Excel в BI-дашборды и выгрузки в реальном времени.
  • Интеграции перевели на брокер сообщений и идемпотентные операции: синхронизация не теряет данные даже при сбоях.
  • Внедрили CI/CD, нагрузочное тестирование и мониторинг: релизы стали частыми и предсказуемыми.

📈 Результат

  • Поиск по справочникам ускорился с секунд до десятков миллисекунд; нагрузка на основную БД снизилась.
  • Отчётность готовится в реальном времени — без ручной сборки и ожидания закрытия периода.
  • Система стабильно работает под пиковыми нагрузками; доступность держится на уровне 99,6%.
  • Интеграции не теряют данные и самовосстанавливаются после сбоев внешних систем.
  • Команда перешла на короткие итерации: новые возможности бизнес получает каждые две недели.
