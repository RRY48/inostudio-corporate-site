Личный кабинет абитуриента: автоматизация процесса поступления

Сервис для приёмной кампании: абитуриент подаёт документы онлайн, следит за статусом заявления и получает уведомления — без очередей и бумажной волокиты.

🎯 Задача

  • Документы подавались в бумажном виде — очереди и ручная обработка в приёмной комиссии.
  • Абитуриент не понимал статус заявления и ждал ответа по телефону.
  • Сотрудникам комиссии приходилось вручную сводить данные из разных форм.
  • В приёмную кампанию нагрузка резко возрастала.

🛠️ Решение

  • Разработали личный кабинет абитуриента: регистрация, подача заявления и загрузка документов.
  • Добавили статусы заявлений и уведомления — абитуриент всегда знает, что происходит.
  • Сделали кабинет сотрудника приёмной комиссии: обработка заявлений и проверка документов.
  • Настроили интеграции с внутренними системами и роли доступа.

📈 Результат

  • Подача документов проходит онлайн — очередей в приёмной комиссии нет.
  • Абитуриент видит статус заявления и получает уведомления.
  • Комиссия обрабатывает заявления быстрее и без ручного сведения данных.
  • Сервис развивается и сопровождается с 2025 года.
Технологии: PHP / Laravel · React · PostgreSQL · REST API
